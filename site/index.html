Palladio 為團隊建立共同語言，串聯起最初的構想與人們每天使用的產品介面。

清晰的基礎規範讓設計與工程團隊減少溝通轉譯的時間，把心力專注在共同做出深思熟慮的決定。

目的不是讓每個產品長得一模一樣，而是讓每一次關鍵決策都清晰易懂、可重複實踐，並對使用它們的人友善體貼。

從設計意圖到產品介面

留給良好判斷發揮空間，系統才能長久實用。

  1. 1
    語意色彩 token

    命名承載用途與意圖，數值調整時無需大費周章重新命名。

  2. 2
    共同語言

    設計與程式碼對齊相同角色語意，而非硬編碼的色碼。

  3. 3
    有意識的留白與間距

    一套標準尺度，確保所有介面表面具備一致的節奏感。

  4. 4
    無障礙介面

    對比度、焦點狀態與動效皆在 token 層級定義，不需在每個畫面個別重複摸索。

套件下載狀態

元件視覺重審期間，暫停提供安裝方式。

現有六個元件（Button、Input、Divider、Badge、Card、Navigation）尚未經過人眼視覺審查，外觀與設計語言的個性有落差，需要重新檢視並調整後才能提供下載。安裝指令將於審查完成、元件外觀確認可用後重新開放。進度可在 GitHub Issue #84 追蹤。
