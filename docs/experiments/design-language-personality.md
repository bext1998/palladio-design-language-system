# 核心個性與視覺原則 P1–P4

- 狀態：Hypothesis
- 舊規格出處：`docs/spec.md` 舊 §1.1、§1.2（P1–P4）
- 假設：Palladio 的視覺世界是「外硬內軟」——靜止時是深碳灰、精準線條、幾何留白的工具感；動起來是流體有機的生命感。具體展開為四條原則：
  - **P1 克制的圓潤**：圓形、圓角、膠囊形狀不是預設，用來標記可互動或柔化焦點；大面積容器傾向直角或小圓角，小型互動元件才是圓潤語彙的主場。
  - **P2 線條是第一公民**：分隔區塊優先用線條與間距而非卡片；1px subtle divider 已足夠建立層次，不需要 shadow 和 border 疊加。
  - **P3 深碳灰的層次**：暗色系是一組有意義的表面層級，色差經過計算，感知得到層次但不碎裂。
  - **P4 流體有機的動效**：迴避線性（機械）與彈跳（活潑但不專業）兩個極端，追求自然加速減速，進場比退場稍慢。
- 輸入：原規格第一章全文；Fable 5.1 對 `docs/spec.md` 的全盤檢視（S1：沒有元件設計規格，agent 只能自己填）；Issue #84、#85（六元件視覺重審與使用者親自設計）。
- 狀態矩陣：尚未針對這四條原則個別做過候選方案的三 density × 多 theme 渲染比較。
- 壓力測試／情境：`Redesign/prototypes/content-creation/` 是第一個依「原型先行」流程產出的探索，但尚未回頭逐條對照 P1–P4 做裁決。
- 證據：`review-artifacts/component-audit/`（六元件現況渲染，非候選方案比較）；`SPEC_ADVERSARIAL_REVIEW-2026-09-13.md` 記錄使用者對六元件外觀「極其不滿意」（Issue #84），代表現有實作未必符合這四條原則描述的效果，或原則本身需要更具體的情境化規則（例如 §4.2 圓角原則已被拆到 `shape-context-principles.md` 單獨處理）。
- 使用者裁決：尚未裁決。
- 結論：維持 Hypothesis。這四條原則本身有方向性價值（可作為候選方案比較時的評分維度），但不能繼續當成「已定案、agent 據此可自行判斷視覺細節」的規則使用——這正是 Issue #85 指出的根因。下一步應依 `docs/experiments/README.md` 的流程，針對至少一個有爭議的具體元件（建議 Navigation，見 Issue #84 的圓角根因）做候選方案比較。
