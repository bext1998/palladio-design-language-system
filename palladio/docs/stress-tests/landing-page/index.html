以 token 提供共同規則，而不是同一套 UI kit

Palladio 是一套開源設計語言與 design-token system：以深碳灰的表面層級、精準線條與流體有機動效建立共同基礎，同時讓每個產品自行定義品牌強調色。所有 accent 狀態由產品明確提供並驗證對比，系統不推導色值；支援 Compact、Default、Spacious 三種密度與 reduced-motion 行為。

背景：深灰色（--pd-color-bg）
